## 4. Student：多教师蒸馏框架

Student 也有完整独立 env 代码：

```text
task/student/tracking_env_cfg.py
  独立基础环境配置
  actor = deployable
  critic = privileged

task/student/config/env_cfg.py
  Track 任务级 env_cfg 的完整副本
  import 的是 task.student.tracking_env_cfg.make_velocity_env_cfg
  不再 import task.track
```

### 观测

```text
student -> actor 组（deployable）
teacher -> critic 组（privileged）
```

### 配置

`task/student/config/rl_cfg.py`：

```text
MultiTeacherDistillationRunnerCfg
  student: 512-256-128 Gaussian
  teacher: 512-256-128 Gaussian
  algorithm: Distillation
  obs_groups = {"student": ("actor",), "teacher": ("critic",)}
  teachers: {terrain_key: checkpoint_path}
  terrain_key: 当前任务
  teacher_checkpoint: 可选覆盖
```

教师模型保留 Gaussian distribution 配置，是为了 strict 加载 PPO actor 的 distribution key；教师前向默认仍是确定性动作。

### Runner

`task/student/config/multi_teacher.py`：

```text
MultiTeacherDistillationRunner(DistillationRunner)
  - 按 terrain_key 从 teachers 选择 teacher checkpoint
  - 初始化时加载 teacher
  - save/load 保留 common_step_counter
  - play 时把 {"actor": True} 映射成 {"student": True}
```

### 教师 checkpoint 注册

`task/student/config/teachers.py`：

```python
TEACHER_CHECKPOINTS = {
    "Flat": "",
    "StairUp": "",
    "StairDown": "",
    "Platform": "",
    "PlumBlossom": "",
    "Stones2Rows": "",
    "TireArray": "",
    "LowClearanceBar": "",
}
```

训练前填入每个地形对应的教师 PPO checkpoint，或者通过：

```text
--agent.teacher-checkpoint <path>
```

覆盖当前任务的教师。

## 7. Teacher / Student train 和 play 脚本

新增 4 个脚本，均支持 `-e/--env <terrain>`：

```text
train/train_teacher.sh
train/train_student.sh
play/play_teacher.sh
play/play_student.sh
```

支持的地形：

```text
flat
stair_up
stair_down
platform
plum
stones
tire
low_clearance_bar
```

### Teacher train

```bash
./train/train_teacher.sh first -e flat
./train/train_teacher.sh first -e stair_up
./train/train_teacher.sh first -e stair_down -p <teacher_run> -m <model>
```

教师任务：

```text
Mjlab-Tracking-<Terrain>-Teacher-Unitree-Go2
```

`-p/-m` 用于恢复教师 PPO 训练。

### Student train

```bash
./train/train_student.sh first -e flat -t <teacher_checkpoint>
./train/train_student.sh first -e stones -t logs/rsl_rl/teacher_model/stone2row
```

- `-t` 指向教师 checkpoint 文件或目录；目录时取最新的 `*.pt`。
- 不传 `-t` 时使用 `task/student/config/teachers.py` 里的注册路径。
- `-p/-m` 用于恢复 student 蒸馏训练，不是教师 checkpoint。

学生任务：

```text
Mjlab-Tracking-<Terrain>-Student-Unitree-Go2
```

### Teacher play

```bash
./play/play_teacher.sh -e flat \
    -c logs/rsl_rl/teacher_model/flat/obs_actor_LALRT_3649.pt
```

- `-c` 可以直接指定任意 `.pt` 文件或目录（目录取最新 `*.pt`）。
- 任务使用 Teacher 任务 ID，actor 观测是特权组 271 维。

### Student play

```bash
./play/play_student.sh -e flat -c <student_checkpoint>
```

- `-c` 可以直接指定 student checkpoint。
- 任务使用 Student 任务 ID，`MultiTeacherDistillationRunner` 会把
  `load_cfg={"actor": True}` 映射成 student 加载。

### 任务注册

`myrobot_mjlab/__init__.py` 现在也会导入：

```python
from myrobot_mjlab.task.teacher import config as teacher_config
from myrobot_mjlab.task.student import config as student_config
```

所以 `uv run train/play` 的 CLI 能直接看到 Teacher / Student 任务 ID。

### 注意

`logs/rsl_rl/teacher_model` 里的现有 checkpoint 是旧 actor 观测
（240 / 267 维），和新的 Teacher 任务（271 维）不兼容；
需要用新的 Teacher 任务重新训练。
