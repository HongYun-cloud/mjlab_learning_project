## 3. Teacher

`task/teacher/config/env_cfg.py` 直接复用 Track 的环境配置，不修改 terrain、reward、event、termination、curriculum。

特权观测只放在 teacher 的 `rl_cfg.py` 里：

```python
obs_groups = {
    "actor": ("critic",),
    "critic": ("critic",),
}
```

也就是说：

```text
teacher env_cfg = track env_cfg
teacher actor 模型输入 = critic 特权组
teacher critic 模型输入 = critic 特权组
```

环境里的 deployable actor 组仍然会被计算，但 teacher actor 不使用它。

默认关闭 RND / symmetry，避免特权观测与 deployable actor 的镜像规则冲突。

## 4. Student：多教师蒸馏框架

### 观测

```text
student -> actor 组（deployable）
teacher -> critic 组（privileged）
```

### 配置

`task/student/config/rl_cfg.py`：

```text
MultiTeacherDistillationRunnerCfg
  student: 512-256-128 Gaussian
  teacher: 512-256-128 Gaussian
  algorithm: Distillation
  obs_groups = {"student": ("actor",), "teacher": ("critic",)}
  teachers: {terrain_key: checkpoint_path}
  terrain_key: 当前任务
  teacher_checkpoint: 可选覆盖
```

教师模型保留 Gaussian distribution 配置，是为了 strict 加载 PPO actor 的 distribution key；教师前向默认仍是确定性动作。

### Runner

`task/student/config/multi_teacher.py`：

```text
MultiTeacherDistillationRunner(DistillationRunner)
  - 按 terrain_key 从 teachers 选择 teacher checkpoint
  - 初始化时加载 teacher
  - save/load 保留 common_step_counter
  - play 时把 {"actor": True} 映射成 {"student": True}
```

### 教师 checkpoint 注册

`task/student/config/teachers.py`：

```python
TEACHER_CHECKPOINTS = {
    "Flat": "",
    "StairUp": "",
    "StairDown": "",
    "Platform": "",
    "PlumBlossom": "",
    "Stones2Rows": "",
    "TireArray": "",
    "LowClearanceBar": "",
}
```

训练前填入每个地形对应的教师 PPO checkpoint，或者通过：

```text
--agent.teacher-checkpoint <path>
```

覆盖当前任务的教师。
