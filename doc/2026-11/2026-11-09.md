## 错位 f 的定义

```text
L = gap + size
f(level) = L * level / 9       (level 0~9)
f(level) = L                   (level 10~12)
```

含义：

```text
level 0:
  第一排最近桩到平台边缘距离 = gap
  第二排最近桩到平台边缘距离 = gap
  两根桩纵向并排，横向净距 = gap

level 9:
  第一排最近桩到平台边缘距离 = gap
  第二排最近桩到平台边缘距离 = gap + L
  两排完全交错
```

同一排相邻桩的纵向间距：

```text
2L
```

因此两排合起来在 `f = L` 时形成间距为 `L` 的交错路径。

## 桩的布置

每个方向：

```text
2 排 × 5 根 = 10 根
```

第一排：

```text
longitudinal = platform_half + gap + size/2 + 2L * k,  k = 0..4
```

第二排：

```text
longitudinal = platform_half + gap + size/2 + f + 2L * k,  k = 0..4
```

横向：

```text
两排中心分别位于 ±L/2
```

所以两排之间的横向净距始终等于 `gap`。

## 目标距离公式

最后离中心最远的桩是第二排第 5 根。

中心平台中心到外侧平台中心：

```text
target_distance
  = platform + 2*gap + size + f + 2*(per_row-1)*(size+gap)
  = platform + 9*size + 10*gap + f
```

其中：

```text
per_row = 5
```

最后一根桩到外侧平台边缘的距离仍为当前 `gap`。

## 11:34 追加修改：按组重新定义纵向间距

前文的 0~9 级布置替换为下面的“组”规则。

### 分组

每个方向 10 根桩，按径向顺序分成 5 组，每组 2 根：

```text
组 1: 第 1 根 + 第 2 根
组 2: 第 3 根 + 第 4 根
...
组 5: 第 9 根 + 第 10 根
```

每组的两根桩分别位于内外两排：

```text
横向中心距 = L
横向净距 = gap
```

### 组内错位

每组第二根相对第一根的纵向错位：

```text
f(level) = L * level / 9     (level 0~9)
f(level) = L                 (level 10~12)
```

### 组间间距

上一组第二根到下一组第一根的纵向中心距固定为：

```text
L
```

因此相邻两组第一根之间的纵向间距为：

```text
L + f
```

### 两个极端

level 0：

```text
f = 0
每组两根并排，组间距 L
径向是 5 组横向对齐的桩
```

level 9：

```text
f = L
组内错位 L，组间间距 L
整条链变成径向间距均匀为 L 的交错桩
```

level 9 与 level 10 几何完全一致，所以 10~12 不需要改动。

### 目标距离

最后一根桩到中心平台边缘的纵向距离：

```text
gap + 5*f + 4*L
```

中心平台中心到外侧平台中心：

```text
target_distance
  = platform + 2*gap + size + 5*f + 4*L
  = platform + 5*size + 6*gap + 5*f
```

## 17:35 追加：train 脚本增加 -c 课程模式

### 用法

```bash
./train/train_stones_2rows_track.sh first -c curriculum
./train/train_stones_2rows_track.sh first -c random
```

`-c` 支持：

```text
curriculum / normal / 0   按课程升级，到最高难度后随机（默认）
random / direct / 1       每次 reset 直接随机难度
```

只对 `train/*_track.sh` 生效；其他脚本会提示忽略。

### 实现

```text
train/lib_train_args.sh
  解析 -c，设置并 export MYROBOT_CURRICULUM_MODE

task/track/tracking_env_cfg.py
  读取 MYROBOT_CURRICULUM_MODE，写入
  curriculum.terrain_levels.params["direct_random"]

task/track/config/env_cfg.py
  Flat 的 curriculum 同样写入 direct_random

config/curriculum/stair_curriculum.py
  direct_random=True 时跳过升降级：
  - 地形任务：每次 reset 在 [0, max_level] 随机
  - 平地任务：每次 reset 在 [min_distance, max_distance] 随机目标距离
```

配置会写进 run 的 `params/env.yaml`，便于复现。

### 当前各 Track 课程上限

```text
Platform:     max_level=12, randomize_at_max=True
Plum:         max_level=12, randomize_at_max=True
Stones-2Rows: max_level=12, randomize_at_max=True
Stair:        max_level=6,  randomize_at_max 默认 True
TireArray:    max_level=6,  randomize_at_max 默认 True
Flat:         无地形等级，目标距离在 2.0~5.0m 之间递增
```

注意：

```text
Stair / TireArray 的 terrain rows = 10，
但 max_level = 6，所以课程最高难度是 level 6，
random 模式也只会随机 0~6，level 7~9 不会使用。
```

如果希望 Stair / TireArray 随机到 0~9，需要把它们的
`max_level` 改成 9。
