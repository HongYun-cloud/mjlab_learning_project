# 2026-11-07 Walkthrough

## 今日目标

- 把梅花桩任务的目标点从固定 `+X` 外侧平地中心，改为在外侧平地靠内区域随机生成。

## 修改内容

### 1. GoalDirectionCommand 支持外部目标点

文件：`config/command/AllTrackingCommand.py`

`_resample_command()` 现在优先使用外部写入的：

```python
command.target_positions[env_ids]
```

如果不存在，再回退到原来的：

```text
target_distances + 四向单位向量
```

这样其他任务不受影响，梅花桩可以通过 event 直接写入随机目标点。

### 2. 新增梅花桩目标采样 event

文件：`config/event/plum_reset.py`

新增：

```python
def randomize_plum_target(...):
```

采样区域：

```text
梅花桩区域半宽：15 / 2 = 7.5m
外侧平地宽度：2.0m
内侧净距：0.3m
使用带宽：0.7m
```

所以目标点满足：

```text
max(|x|, |y|) ∈ [7.8, 8.5]
```

也就是始终落在绿色外侧平地的靠内区域，不会落到梅花桩上，也不会太靠近平地外缘。

采样方式：

- 随机选择上、下、左、右四条边。
- 沿边随机位置。
- 向平地内侧随机深度。
- 每个 env 独立采样。

### 3. 接入 Plum env_cfg

文件：`task/track/config/env_cfg.py`

在 `my_go2_plum_env_cfg()` 的 reset events 中加入：

```python
"randomize_goal": EventTermCfg(
    func=randomize_plum_target,
    mode="reset",
    params={
        "command_name": "Goal_direction",
        "inner_margin": 0.3,
        "inner_band": 0.7,
    },
),
```

保留原来的 `target_distance=8.5` 作为 fallback；实际每次 reset 都会由 event 覆盖目标点。

### 4. 目标点不再固定方向

以前：

```text
target = (8.5, 0.0)
```

现在：

```text
target = 外侧平地靠内区域的随机点
```

所以机器人可能需要向任意方向转身并穿越梅花桩。

使用 4 个 env、连续 reset 4 次：

```text

  [-8.233,  5.368]
  [ 2.937, -8.000]

  [ 8.175,  3.980]

  [ 1.835,  8.208]

reset 3 targets:
  [-7.950,  5.388]

```

均落在目标区间 `[7.8, 8.5]` 内，且每次 reset 目标都会变化。

## 注意

- `target_positions` 使用 env 局部坐标（相对 env origin），和原来的 `target_pos` 口径一致。
- 目标高度仍然由 `Base_height_target` 处理，不需要在 XY 目标里存 z。
- 其他任务没有 `target_positions` 属性，仍然走原来的四向 + 距离逻辑。
- 当前目标区域是“外侧平地的靠内 0.3m ~ 1.0m 带”，如果想让目标更靠外或更靠内，调整：

```python
inner_margin
inner_band
```
