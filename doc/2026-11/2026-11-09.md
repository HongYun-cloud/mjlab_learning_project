## 错位 f 的定义

```text
L = gap + size
f(level) = L * level / 9       (level 0~9)
f(level) = L                   (level 10~12)
```

含义：

```text
level 0:
  第一排最近桩到平台边缘距离 = gap
  第二排最近桩到平台边缘距离 = gap
  两根桩纵向并排，横向净距 = gap

level 9:
  第一排最近桩到平台边缘距离 = gap
  第二排最近桩到平台边缘距离 = gap + L
  两排完全交错
```

同一排相邻桩的纵向间距：

```text
2L
```

因此两排合起来在 `f = L` 时形成间距为 `L` 的交错路径。

## 桩的布置

每个方向：

```text
2 排 × 5 根 = 10 根
```

第一排：

```text
longitudinal = platform_half + gap + size/2 + 2L * k,  k = 0..4
```

第二排：

```text
longitudinal = platform_half + gap + size/2 + f + 2L * k,  k = 0..4
```

横向：

```text
两排中心分别位于 ±L/2
```

所以两排之间的横向净距始终等于 `gap`。

## 目标距离公式

最后离中心最远的桩是第二排第 5 根。

中心平台中心到外侧平台中心：

```text
target_distance
  = platform + 2*gap + size + f + 2*(per_row-1)*(size+gap)
  = platform + 9*size + 10*gap + f
```

其中：

```text
per_row = 5
```

最后一根桩到外侧平台边缘的距离仍为当前 `gap`。

## 11:34 追加修改：按组重新定义纵向间距

前文的 0~9 级布置替换为下面的“组”规则。

### 分组

每个方向 10 根桩，按径向顺序分成 5 组，每组 2 根：

```text
组 1: 第 1 根 + 第 2 根
组 2: 第 3 根 + 第 4 根
...
组 5: 第 9 根 + 第 10 根
```

每组的两根桩分别位于内外两排：

```text
横向中心距 = L
横向净距 = gap
```

### 组内错位

每组第二根相对第一根的纵向错位：

```text
f(level) = L * level / 9     (level 0~9)
f(level) = L                 (level 10~12)
```

### 组间间距

上一组第二根到下一组第一根的纵向中心距固定为：

```text
L
```

因此相邻两组第一根之间的纵向间距为：

```text
L + f
```

### 两个极端

level 0：

```text
f = 0
每组两根并排，组间距 L
径向是 5 组横向对齐的桩
```

level 9：

```text
f = L
组内错位 L，组间间距 L
整条链变成径向间距均匀为 L 的交错桩
```

level 9 与 level 10 几何完全一致，所以 10~12 不需要改动。

### 目标距离

最后一根桩到中心平台边缘的纵向距离：

```text
gap + 5*f + 4*L
```

中心平台中心到外侧平台中心：

```text
target_distance
  = platform + 2*gap + size + 5*f + 4*L
  = platform + 5*size + 6*gap + 5*f
```

## 11:47 追加：Stones-2Rows 增加掉出世界终止

### 新终止项

只加到 `my_go2_stones_2rows_env_cfg()`：

```python
cfg.terminations["base_below_world"] = TerminationTermCfg(
  func=base_below_height,
  params={"min_height": -3.0},
)
```

终止函数位于：

```text
config/event/stones_reset.py
```

```python
def base_below_height(env, min_height=-3.0, asset_cfg=SceneEntityCfg("robot")):
    asset = env.scene[asset_cfg.name]
    return asset.data.root_link_pos_w[:, 2] < min_height
```

判断的是机身 root link 的世界 z 坐标。

### 行为

```text
z >= -3.0: 不终止
z <  -3.0: 终止
```

`time_out` 使用默认值 `False`，所以这是真正的失败终止，
会触发 `termination_penalty`（当前 -200）。

### 范围

- 只在 Stones-2Rows 注册。
- Stair / Platform / Plum / Tire 等其他任务不受影响。

### 验证

- reset 后机身 z 约为 `0.48m`，不触发。
- 手动把机身 z 写到 `-4.0m` 后：

```text
base_below_world = True
dones = True
time_outs = False
```

即正常作为失败终止处理。
