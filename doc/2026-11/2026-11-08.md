## 路径结构

每个方向：

```text
2 排 × 5 根 = 10 根桩
```

沿路径交错放置：

```text
position 0: 左排
position 1: 右排
position 2: 左排
...
position 9: 右排
```

横向行距：

```text
size + gap
```

纵向位置：

```text
第一根桩到中心平台边缘距离 = gap
后续相邻桩净距 = gap
最后一根桩到外侧平台边缘距离 = gap
```

因此从中心平台中心到外侧平台中心的距离：

```text
target_distance = platform_size + 10*size + 11*gap
```

## 外侧平台和目标

四个方向各一个外侧平台：

```text
E / W / N / S
```

外侧平台尺寸与中心平台相同。

目标点固定在四个外侧平台中心，每次 reset 随机选一个方向。
