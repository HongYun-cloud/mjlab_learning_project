# 2026-11-09 Walkthrough

## 今日修改

重新设计 Stones-2Rows 的 0~9 级课程：

- 桩尺寸固定为 `0.2m`，不再随难度变化。
- `gap` 保持原来的 `0.01 -> 0.20`。
- 两排桩的纵向错位 `f` 从 `0` 线性增加到 `L = gap + size`。
- 10~12 级几何不变（仍是 `f = L`、`gap = 0.2`、`size = 0.2`）。

## 错位 f 的定义

```text
L = gap + size
f(level) = L * level / 9       (level 0~9)
f(level) = L                   (level 10~12)
```

含义：

```text
level 0:
  第一排最近桩到平台边缘距离 = gap
  第二排最近桩到平台边缘距离 = gap
  两根桩纵向并排，横向净距 = gap

level 9:
  第一排最近桩到平台边缘距离 = gap
  第二排最近桩到平台边缘距离 = gap + L
  两排完全交错
```

同一排相邻桩的纵向间距：

```text
2L
```

因此两排合起来在 `f = L` 时形成间距为 `L` 的交错路径。

## 桩的布置

每个方向：

```text
2 排 × 5 根 = 10 根
```

第一排：

```text
longitudinal = platform_half + gap + size/2 + 2L * k,  k = 0..4
```

第二排：

```text
longitudinal = platform_half + gap + size/2 + f + 2L * k,  k = 0..4
```

横向：

```text
两排中心分别位于 ±L/2
```

所以两排之间的横向净距始终等于 `gap`。

## 目标距离公式

最后离中心最远的桩是第二排第 5 根。

中心平台中心到外侧平台中心：

```text
target_distance
  = platform + 2*gap + size + f + 2*(per_row-1)*(size+gap)
  = platform + 9*size + 10*gap + f
```

其中：

```text
per_row = 5
```

最后一根桩到外侧平台边缘的距离仍为当前 `gap`。
